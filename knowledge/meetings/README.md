# meetings/

## What belongs here

Append-only notes from conversations that matter — investor calls, customer discovery interviews, clinician conversations, advisor sessions, partnership talks, candidate interviews. Each meeting gets its own file. **Never edited after creation.** If something said in a meeting later turns out to be wrong, that's recorded in a new note or in the relevant knowledge file — the original meeting record stays as-is.

### Naming

`YYYY-MM-DD-topic-or-counterparty.md`

Example: `2026-05-20-discovery-call-acme-health-system.md`

### Structure (suggested)

```markdown
---
title: <Meeting title>
description: Who, what, one-line outcome
last_updated: YYYY-MM-DD
updated_by: ion | Emilio
status: active
---

## Attendees
- Emilio Escartin
- <Other names + roles>

## Context
Why this meeting happened.

## Notes
Key points discussed.

## Decisions / Next Steps
- [ ] Action — **Owner: Name** — Due: YYYY-MM-DD

## Related
[[wiki-links]]
```

Action items captured here should also be mirrored into `ops/action-items.md` so they show up in the daily checklist.
