# customers/

## What belongs here

Who EBDA Ventures serves — and for a venture studio that means multiple constituencies. Healthcare-system buyers and clinicians for the portfolio companies. LPs and co-investors for the studio itself. Talent (operators-in-residence, founders, advisors). Track personas, target accounts, ICP definitions, interview notes, and feedback signals.

Typical files: `icp.md`, `personas/<role>.md`, `target-accounts.md`, `discovery-interviews.md`, `lp-prospects.md`.
