# product/

## What belongs here

What the venture studio actually builds — the operating model, the playbook for spinning up portfolio companies, the shared platform/tools/IP, and the product theses for each company being incubated. For a venture studio specifically: the *studio* is a product, and each *startup it launches* is a product. Both live here.

Typical files: `studio-playbook.md`, `operating-model.md`, `incubation-process.md`, `shared-platform.md`, `portfolio/<company-name>.md` for each startup being built.
